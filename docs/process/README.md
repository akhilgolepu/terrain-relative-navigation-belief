# Process documents

Working instructions used to direct Claude Code during development; kept to show how the work was specified and
reviewed.

- `CLAUDE.md`: the standing project instructions (goal, environment, rules such as "never report a metric not
  computed by a script", "test splits are whole flights", "never fit on the test flight").
- `WEEK1_BRIEF.md`, `WEEK2_8_BRIEFS.md`: the week-by-week briefs. The detailed instructions given each week, and
  what was done with them, are recorded in `docs/log.md`.

These files were at the repository root (`CLAUDE.md`) and in `docs/` (the briefs) during development; references to
those paths in `docs/log.md` and inside the briefs mean the files in this folder.
