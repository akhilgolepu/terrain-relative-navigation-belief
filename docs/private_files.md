# Files that must stay private (label-derived positions)

UAV-VisLoc is academic use only and forbids redistribution. The files below are tracked in git and contain positions derived from the dataset labels (ENU east/north of labels, priors, fixes or candidates, or latitude/longitude). The repository stays private; nothing is pushed. Before anything is published, these files (and their git history) must be removed, or the publication must be a fresh repository without them.

Not tracked at all (git-ignored, stay on this machine): dataset images, map chips, overlays, failure overlays, matcher caches (`eval/results/week7/closed_loop/runs/*.cache.jsonl`, `eval/results/test_flight11/private/`), the rosbag (`~/data/rosbags/`).
